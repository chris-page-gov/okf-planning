# Pipeline

* [Expectation Log](expectation.md) - The output of running expectations based on the rules defined in the expect dataset
* [Expectation Rule](expect.md) - A set of rules which can be turned into an expectation of a dataset
* [Pipeline column](column.md) - Map resource column name to dataset field
* [Pipeline default field](default.md) - Take a missing field default value from another field
* [Pipeline default value](default-value.md) - provide a default value for a missing or empty field
* [Task](task.md) - Tasks are an amalgamation of the various data quality checks that are run in the pipeline that need to be fixed (e.g. issues, expectations, collection logs).
