# Licensing decisions

Repository-authored code follows the existing [MIT licence](LICENSE).
Publisher material retains the source-specific licence and attribution recorded
on each catalogue entry. The repository licence does not replace those terms.

The frozen catalogue envelopes and curated records are retained as the existing
metadata source plane. This format migration does not refresh source material or
add property-level records, planning decisions or external data downloads.
Rights statements remain source declarations, rather than a new legal review.
An absent or uncertain right must remain labelled as such.

The [metadata profile](profiles/planning-metadata/v1/README.md),
[semantic contract](okf.semantic.json) and [publication contract](okf.publication.json)
record the source and projection boundaries. Review rights again before changing
the acquired source families or redistributing additional publisher material.
