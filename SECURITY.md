# Security

Report suspected vulnerabilities privately to the repository owner. Keep secrets,
personal data, exploit payloads and restricted source material out of public
issues.

Treat acquired content, catalogue values and declared command strings as
untrusted data. Review commands against the local guidance before execution.
Publication follows the protected-main checks and exact-candidate gates declared
in `okf.publication.json`. The metadata-only MCP component grants no permission
to execute a planning or government service.
